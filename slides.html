I/O multiplexing là gì?

Một thread theo dõi nhiều socket. Kernel báo cái nào ready → code chỉ làm việc khi có sự kiện.

  • → Không cần 1 thread per connection.
  • → Không busy-poll read().
  • → Scale tốt với hàng ngàn conn.

2 mô hình lớn

Readiness

Kernel báo "đọc được", code tự gọi recv(). (epoll, kqueue, WSAPoll, select, poll)

Completion

Code post recv() trước, kernel báo khi đã đọc xong. (IOCP, io_uring)

epoll — vòng lặp chính server_linux.go

for {
    n, err := syscall.EpollWait(epfd, events, -1) // block vô hạn
    if err == syscall.EINTR { continue } // bị signal, lặp lại

    for i := 0; i < n; i++ {
        efd := int(events[i].Fd)

        if efd == listener {
            for { // vòng accept vì non-blocking
                cfd, _, err := syscall.Accept4(listener, SOCK_NONBLOCK|SOCK_CLOEXEC)
                if err != nil { break } // EAGAIN = hết pending
                epollAdd(epfd, cfd)
            }
            continue
        }
        handleConnLinux(efd) // read → parse → write → close
        syscall.EpollCtl(epfd, EPOLL_CTL_DEL, efd, nil)
    }
}

Linux · io_uring

completion model — kernel ≥ 5.4

Hai ring shared memory: SQ (user → kernel) và CQ (kernel → user). Build: go build -tags iouring.

1

io_uring_setup(entries)

Trả ring fd + offsets cho SQ/CQ trong mmap.

2

mmap SQ + CQ + SQE array

Nếu FEAT_SINGLE_MMAP → SQ & CQ chung 1 mmap.

3

Socket + Bind + Listen

TCP/IPv4 thường, không cần non-blocking.

4

Submit SQE: IORING_OP_ACCEPT

Điền SQE slot, update sq_tail (atomic).

5

io_uring_enter(GET_EVENTS)

Kernel pull SQE, push CQE; block đến khi ≥ minComplete.

6

Drain CQE → dispatch

Accept → submit Recv + Accept mới; Recv → Send; Send hết byte → close.

io_uring — Shared Ring Buffer: zero-copy giữa User & Kernel

User — submit op

sqe = getSqe() // lấy slot
sqe.Opcode = ACCEPT / RECV / SEND
sqe.Fd = fd
sqe.Addr = &buf
atomic.Store(sq_tail, sq_tail+1) // publish

Kernel — process op

sq_head = atomic.Load(sq_head)
sqe = sqes[sq_head & mask] // đọc op
thực hiện: accept / recv / send
atomic.Store(sq_head, sq_head+1)

Shared mmap — không cần copy, không cần lock (single-threaded loop)

SQ Ring

sq_head← kernel đọc
sq_tail← user ghi
sq_mask= entries-1
sq_array[]index → SQE

SQE Array (64B × entries)

[0] ACCEPT fd:3
[1] RECV fd:5 buf
[2] SEND fd:5 resp
...

CQ Ring

cq_head← user đọc
cq_tail← kernel ghi
cqe.UserData= op id
cqe.Res= fd / len

io_uring_enter(ring_fd, submit, minWait, GET_EVENTS)

1 syscall có thể submit N SQE + block cho đến khi có ≥ minWait CQE.
Với IORING_FEAT_SQPOLL: kernel poll SQ background → 0 syscall ở hot path.

User — drain CQE (không cần syscall)

head = atomic.Load(cq_head)
tail = atomic.Load(cq_tail) // kernel ghi
for head != tail {
c = cqes[head & cqMask]
dispatch(opMap[c.UserData])
atomic.Store(cq_head, head+1)
}

io_uring — vòng lặp chính server_linux_iouring.go

// UserData = id (uint64) tra ra *ioOp qua opMap — tránh uintptr↔Pointer round-trip.
r.submitAccept(listener, &ioOp{kind: opAccept, fd: listener})

for {
    r.enter(r.params.SqEntries, 1, enterGetEvents) // io_uring_enter, block tới khi ≥1 CQE

    for {
        head := atomic.LoadUint32(r.cqHead)
        tail := atomic.LoadUint32(r.cqTail)
        if head == tail { break } // drain hết CQ ring
        c := r.cqes[head&r.cqMask]
        o := opMap[c.UserData]

        switch o.kind {
        case opAccept:
            if c.Res >= 0 { r.submitRecv(c.Res, &ioOp{kind: opRecv, fd: c.Res}) }
            r.submitAccept(o.fd, &ioOp{kind: opAccept, fd: o.fd}) // replenish

        case opRecv:
            method, path, _ := parseRequest(o.buf[:c.Res])
            resp := buildResponse(method, path)
            r.submitSend(o.fd, resp, &ioOp{kind: opSend, fd: o.fd, sendData: resp})

        case opSend:
            o.sendOff += int(c.Res)
            if o.sendOff >= len(o.sendData) { syscall.Close(int(o.fd)) }
            else { r.submitSend(o.fd, o.sendData[o.sendOff:], o) } // repost phần còn lại
        }
        atomic.StoreUint32(r.cqHead, head+1)
    }
}

epoll vs io_uring — hai mô hình trên cùng kernel

epoll · readiness

  • Kernel báo "fd ready" → user gọi read/write trong syscall riêng.
  • Mỗi I/O = ít nhất 1 syscall (chưa kể epoll_ctl).
  • Buffer cấp khi gọi read.
  • Chỉ bao phủ thao tác pollable (socket, pipe, eventfd…).
  • Cần fd non-blocking + loop EAGAIN.

io_uring · completion

  • User submit op (accept/recv/send/…) — kernel làm xong rồi báo qua CQE.
  • Batch submit + batch reap qua shared ring, 1 syscall = N op.
  • Buffer pin trước khi submit (Addr/Len trong SQE).
  • Hỗ trợ file, socket, splice, fsync, nhiều op linked.
  • Có SQPOLL để kernel poll SQ → 0 syscall ở hot path.

Giống IOCP của Windows ở chỗ "post op → đợi completion", khác ở chỗ ring nằm trong shared mmap thay vì queue ẩn trong kernel.

kqueue — vòng lặp chính server_darwin.go

for {
    n, err := syscall.Kevent(kq, nil, events, nil) // changes=nil → chỉ wait
    if err == syscall.EINTR { continue }

    for i := 0; i < n; i++ {
        efd := int(events[i].Ident) // Ident = fd

        if efd == listener {
            for {
                cfd, _, err := syscall.Accept(listener)
                if err != nil { break }
                syscall.SetNonblock(cfd, true)
                kqueueAdd(kq, cfd) // EVFILT_READ | EV_ADD
            }
            continue
        }
        handleConnDarwin(efd) // close tự gỡ khỏi kqueue
    }
}

Windows · IOCP

completion model — khác hẳn

Post thao tác (Accept/Recv/Send) cùng OVERLAPPED → kernel làm xong → post completion vào port → worker pick up.

1

WSAStartup

Khởi tạo Winsock 2.2.

2

WSASocketW + WSA_FLAG_OVERLAPPED

Bắt buộc cờ overlapped để dùng IOCP.

3

CreateIoCompletionPort

Tạo IOCP, gắn listener vào.

4

Pre-post 8 × AcceptEx

Mỗi cái: tạo socket trống + AcceptEx (overlapped).

5

GetQueuedCompletionStatus loop

Kernel trả về OVERLAPPED ptr → cast ngược về *ioOp.

6

Dispatch theo opKind

Accept → Recv → Send → close. Mỗi op pin trong map đến khi completion.

IOCP — worker dispatch server_windows.go

for {
    var nbytes, key uint32
    var po *syscall.Overlapped
    cerr := syscall.GetQueuedCompletionStatus(iocp, &nbytes, &key, &po, INFINITE)
    o := (*ioOp)(unsafe.Pointer(po)) // overlapped offset 0 → cast về op

    switch o.kind {
    case opAccept:
        syscall.Setsockopt(o.sock, SOL_SOCKET, SO_UPDATE_ACCEPT_CONTEXT, ...)
        syscall.CreateIoCompletionPort(o.sock, iocp, 0, 0)
        postRecv(o.sock)
        postAccept(o.listener) // replenish slot

    case opRecv:
        method, path, _ := parseRequest(o.buf[:nbytes])
        postSend(o.sock, buildResponse(method, path))

    case opSend:
        o.sendOff += int(nbytes)
        if o.sendOff >= len(o.sendData) { syscall.Closesocket(o.sock) }
        else { syscall.WSASend(o.sock, ...) } // repost phần còn lại
    }
}
