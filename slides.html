I/O multiplexing là gì?

Một thread theo dõi nhiều socket. Kernel báo cái nào ready → code chỉ làm việc khi có sự kiện.

  • → Không cần 1 thread per connection.
  • → Không busy-poll read().
  • → Scale tốt với hàng ngàn conn.

2 mô hình lớn

Readiness

Kernel báo "đọc được", code tự gọi recv(). (epoll, kqueue, WSAPoll, select, poll)

Completion

Code post recv() trước, kernel báo khi đã đọc xong. (IOCP, io_uring)

Linux · epoll

readiness model

Kernel object epfd giữ tập fd. epoll_wait trả về chỉ fd nào ready.

1

Socket + Bind + Listen

SOCK_NONBLOCK | SOCK_CLOEXEC, SO_REUSEADDR.

2

epoll_create1()

Tạo kernel object → epfd.

3

epoll_ctl(ADD, listener, EPOLLIN)

Đăng ký listener vào epfd.

4

epoll_wait()

Block đến khi có fd ready. Kernel trả list các fd có event.

5

Nếu fd = listener

Loop accept4() đến EAGAIN, mỗi client mới → epoll_ctl(ADD).

6

Nếu fd = client

read → parse → write → close + EPOLL_CTL_DEL.

epoll — vòng lặp chính server_linux.go

for {
    n, err := syscall.EpollWait(epfd, events, -1) // block vô hạn
    if err == syscall.EINTR { continue } // bị signal, lặp lại

    for i := 0; i < n; i++ {
        efd := int(events[i].Fd)

        if efd == listener {
            for { // vòng accept vì non-blocking
                cfd, _, err := syscall.Accept4(listener, SOCK_NONBLOCK|SOCK_CLOEXEC)
                if err != nil { break } // EAGAIN = hết pending
                epollAdd(epfd, cfd)
            }
            continue
        }
        handleConnLinux(efd) // read → parse → write → close
        syscall.EpollCtl(epfd, EPOLL_CTL_DEL, efd, nil)
    }
}

macOS · kqueue

readiness model — họ hàng BSD

Generic event interface: socket, file, signal, timer, process — gói trong "filter".

1

Socket + Bind + Listen

SetNonblock thủ công (không có flag trong Socket()).

2

Kqueue()

Tạo kernel queue object.

3

Kevent ADD + EVFILT_READ

Đăng ký listener. Cùng 1 syscall vừa add vừa lấy event (batch được).

4

Kevent(changes=nil) → wait

Lấy event ready (Ident = fd).

5

Listener event

Accept loop, SetNonblock client, đăng ký vào kqueue.

6

Client event

read → parse → write → close. Close tự gỡ khỏi kqueue.

kqueue — vòng lặp chính server_darwin.go

for {
    n, err := syscall.Kevent(kq, nil, events, nil) // changes=nil → chỉ wait
    if err == syscall.EINTR { continue }

    for i := 0; i < n; i++ {
        efd := int(events[i].Ident) // Ident = fd

        if efd == listener {
            for {
                cfd, _, err := syscall.Accept(listener)
                if err != nil { break }
                syscall.SetNonblock(cfd, true)
                kqueueAdd(kq, cfd) // EVFILT_READ | EV_ADD
            }
            continue
        }
        handleConnDarwin(efd) // close tự gỡ khỏi kqueue
    }
}

Windows · IOCP

completion model — khác hẳn

Post thao tác (Accept/Recv/Send) cùng OVERLAPPED → kernel làm xong → post completion vào port → worker pick up.

1

WSAStartup

Khởi tạo Winsock 2.2.

2

WSASocketW + WSA_FLAG_OVERLAPPED

Bắt buộc cờ overlapped để dùng IOCP.

3

CreateIoCompletionPort

Tạo IOCP, gắn listener vào.

4

Pre-post 8 × AcceptEx

Mỗi cái: tạo socket trống + AcceptEx (overlapped).

5

GetQueuedCompletionStatus loop

Kernel trả về OVERLAPPED ptr → cast ngược về *ioOp.

6

Dispatch theo opKind

Accept → Recv → Send → close. Mỗi op pin trong map đến khi completion.

IOCP — worker dispatch server_windows.go

for {
    var nbytes, key uint32
    var po *syscall.Overlapped
    cerr := syscall.GetQueuedCompletionStatus(iocp, &nbytes, &key, &po, INFINITE)
    o := (*ioOp)(unsafe.Pointer(po)) // overlapped offset 0 → cast về op

    switch o.kind {
    case opAccept:
        syscall.Setsockopt(o.sock, SOL_SOCKET, SO_UPDATE_ACCEPT_CONTEXT, ...)
        syscall.CreateIoCompletionPort(o.sock, iocp, 0, 0)
        postRecv(o.sock)
        postAccept(o.listener) // replenish slot

    case opRecv:
        method, path, _ := parseRequest(o.buf[:nbytes])
        postSend(o.sock, buildResponse(method, path))

    case opSend:
        o.sendOff += int(nbytes)
        if o.sendOff >= len(o.sendData) { syscall.Closesocket(o.sock) }
        else { syscall.WSASend(o.sock, ...) } // repost phần còn lại
    }
}
